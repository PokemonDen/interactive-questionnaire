## 🎯 Что это?

**Интерактивный опросный лист для проектирования микроЦОД** — это готовый к использованию инструмент для пресейл-инженеров, который позволяет:

- 📝 Собрать **все технические требования** к проекту микроЦОД в едином интерфейсе
- 📍 Визуально оценить **размещение внешних блоков** кондиционера с интерактивной зонной картой
- 🔌 Определить требования к **электропитанию, охлаждению и резервированию**
- 🖨️ **Сохранить результат в PDF** одной кнопкой (готовый документ для передачи заказчику)
